# League of Heroes — Roll20 Sync

Расширение Manifest V3 связывает открытый чарник Roll20 с персонажем в Supabase.

Версия 0.6.0 размещает инструменты по логике VTTES: синхронизация персонажа
остаётся во вкладке «League of Heroes», а «Token Editor» становится отдельной
вкладкой чарника. Доступны работа с Represents, изображением, размерами,
поворотом, полосами, аурами, правами, обновлённым и устаревшим динамическим
освещением. Можно обновлять выбранный, все связанные и стандартный токен
персонажа.

## Установка для тестирования

1. В кабинете игрока создайте персонажа.
2. В Chrome или Яндекс Браузере откройте страницу расширений и включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. Вернитесь в кабинет Лиги и нажмите «Подключить расширение». Сайт сам передаст публичные параметры Supabase и создаст личный ключ `loh_…`.
5. Откройте игровую комнату Roll20 и один чарник. В списке вкладок листа появятся «League of Heroes» и «Token Editor».

После обновления файлов расширения обязательно нажмите «Обновить» на странице расширений и полностью перезагрузите вкладку игровой комнаты Roll20.

## Двусторонняя синхронизация

- «Загрузить из Лиги» переносит полный подготовленный `roll20_data`, затем накладывает последние игровые значения.
- «Сохранить в Лиге» экспортирует открытый чарник целиком в совместимый с VTTES JSON: атрибуты, повторяющиеся секции, способности, bio, gmnotes, токен и права доступа.
- Если герой Лиги выбран, его `roll20_data` полностью обновляется. Если список пуст, расширение создаёт героя в свободном слоте кабинета.
- Персонажи, созданные вручную непосредственно в Roll20, поддерживаются так же, как герои конструктора.

Перезапись модели Roll20 использует совместимый с VTT Enhancement Suite порядок: очистка коллекций, замена ID исходного персонажа и повторное создание атрибутов и способностей. Соответствующая часть расширения распространяется по GPL-3.0; текст лицензии находится в `LICENSE`.

Перед использованием настройте базу по `supabase/README.md` и выполните
`supabase/verify-installation.sql`. Для существующей базы нужна миграция
`supabase/migrations/20260803_full_roll20_sync.sql`, а затем
`supabase/migrations/20260803_02_fix_pgcrypto_search_path.sql`; всю `schema.sql`
повторно запускать не следует.
